# SO-ARM101 Kinematics Core — 순기구학·역기구학 근본 구현

로봇 도면(URDF)에서 시작해 **관절각 ↔ 손끝 위치**를 계산하는 최소 코어.
시뮬레이터도, 로봇 드라이버도, 프레임워크도 없이 **numpy만으로** 돌아간다.

```
fk_core.py    순기구학 (POE, Product of Exponentials)   — numpy만
ik_core.py    역기구학 (자코비안 + 감쇠최소자승 DLS)      — numpy만
so101.urdf    로봇 도면 (링크 길이·회전축·관절 한계)
```

---

## 바로 실행

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install numpy

python fk_core.py      # 홈자세 손끝 위치 + 관절 한계 출력

```

기대 출력 (IK 자기검증):
```
목표(FK[0, 30, -45, 0, 0]) = [434.6  -0.  273.6] mm
  IK해(도) = [ -0.   30.  -45.    0.    0.]   잔차 = 0.00 mm
```

## 1. 순기구학 — `fk_core.py`

**"관절 각도를 알면 손끝이 어디인지 계산한다."**

### 방법: POE (지수좌표)

Modern Robotics Ch.4 규약. URDF에서 두 가지를 뽑아 쓴다.

- **M** — 모든 관절이 0일 때(홈자세)의 손끝 변환행렬
- **Sᵢ** — 각 관절의 **스크루축** (회전축 방향 ω + 위치항 v)

그러면 손끝 자세는 지수사상의 곱:

```
T(q) = exp([S₁]q₁) · exp([S₂]q₂) · … · exp([S₅]q₅) · M
```

```python
from fk_core import FKSo101
fk = FKSo101()

T = fk.fk([0, 0.5, -0.8, 0, 0])        # 라디안 5개 → 4x4 변환행렬
p, R = fk.fk_deg([0, 30, -45, 0, 0])   # 도(degree) 5개 → 위치, 회전
print(p)                                # [0.4346, 0.0, 0.2736] (미터)
print(fk.limits_deg())                  # 관절별 한계 (URDF에서 읽음)
```

### 왜 DH가 아니라 POE인가
DH 파라미터는 링크마다 좌표계를 새로 잡아야 하고 규약이 갈린다.
POE는 **모든 축을 베이스 좌표계 하나에서** 기술하므로 URDF에서 기계적으로 추출되고, 부호 실수가 적다.

### 검증됨
컨트롤러 3D 트윈과 동일한 좌표를 낸다.
서보 원시값 → 라디안 변환이 `(pos-2048)/4095·2π` 이므로, SDK가 주는 `angle_deg`를 그대로 `radians()` 하면 URDF 관절각과 일치한다.

## 2. 역기구학 — `ik_core.py`

**"손끝을 여기로 보내려면 관절 각도가 몇인가."**

5축 팔에서는 닫힌 해가 없다. 그래서 **수치 해법**으로 푼다.

### 알고리즘 (한 번의 반복)

```
1. 현재 각도 q 의 손끝 위치를 계산한다            ← FK 호출
2. 오차 e = 목표 − 현재
3. 자코비안 J 를 구한다 (3×5, 유한차분)          ← FK 를 10번 호출
4. dq = Jᵀ (J Jᵀ + λ²I)⁻¹ e                    ← 감쇠 최소자승(DLS)
5. q ← q + dq   (관절 한계로 clip)
```

- **IK는 FK를 수백 번 호출하는 과정이다.** 오차를 재려면 현재 손끝을 알아야 하므로.
- **자코비안 J는 3행 5열** — 출력(위치 3) < 입력(관절 5). 즉 **답이 무한히 많다**(여유자유도 2).
  그중 "가장 조금 움직이는 해"를 고르는 것이 우측 유사역행렬 `Jᵀ(JJᵀ)⁻¹`.
- **λ (damp)** 가 없으면 특이점 근처에서 dq가 폭발한다. 감쇠가 그 안전벨트.
- 자코비안을 **유한차분**으로 구하므로 FK와 100% 일치한다(해석적 미분의 부호 실수가 원천 배제).

```python
from ik_core import IKSo101
ik = IKSo101()

angles_deg, err = ik.solve([0.25, 0.05, 0.15])     # 목표 위치(m) → 관절각(도), 잔차(m)
print(angles_deg, err)                              # 잔차 2cm 넘으면 도달 범위 밖

# 시작 자세를 지정하면 그 근처의 해를 찾는다 (답이 여러 개이므로)
angles_deg, err = ik.solve([0.25, 0.05, 0.15], seed_deg=[0, 30, -45, 0, 0])
```

### `down=True` — 아래보기 파지 모드 (선택)

그리퍼가 수직 아래를 향하도록 **방향 조건 3줄을 자코비안에 추가**한다(6×5).

```python
angles_deg, err = ik.solve([0.24, 0.05, 0.06], down=True)
```

⚠️ 이 모드만 **mujoco + `models/SO101/scene.xml`** 이 필요하다 (방향 자코비안 계산에 `mj_jacSite` 사용).
이 저장소에는 모델이 포함돼 있지 않으므로, 위치 전용(`down=False`, 기본값)만 numpy로 완전히 동작한다.

그리고 여기서 **5축의 한계**가 드러난다 — 위치(3) + 방향(3) = 6 조건을 5개 관절로 다 만족할 수 없어서
허용 잔차를 2cm에서 12cm로 풀어야 통과한다. 6축 로봇이 산업 표준인 이유가 이것이다.

## 3. 좌표계

`python fk_core.py` 로 확인한 실측:

| 축 | 방향 | 근거 |
|---|---|---|
| **+x** | 팔이 뻗는 앞쪽 | 홈자세에서 x=+434mm |
| **+y** | 로봇에서 봤을 때 왼쪽 | 1번 관절 −30° → y=+198mm |
| **+z** | 위 | 팔을 펴면 증가 |

원점은 로봇 밑동(`base_link`), 손끝 기준점은 `gripper_frame_link`. 단위는 **미터**.

## 4. 파일 안내

| 파일 | 내용 |
|---|---|
| `fk_core.py` | SE(3) 도구(`_skew`/`_exp3`/`_exp6`) · URDF 파서 · `FKSo101` 클래스 |
| `ik_core.py` | 유한차분 자코비안 · DLS 반복 · `IKSo101` 클래스 |
| `so101.urdf` | 링크 원점·회전축·관절 한계. **이 파일이 곧 로봇 도면** |

두 파일 모두 `python <파일>` 로 직접 실행하면 자기검증 데모가 돈다.

---

## 5. 어디에 쓰나

- **좌표 → 관절각**: `ik.solve(xyz)` 결과를 서보에 그대로 전송
- **관절각 → 좌표**: `fk.fk_deg(deg5)` 로 현재 손끝 위치 추정 (실물은 site를 못 읽으므로 FK로 계산)
- **캘리브레이션**: 토크를 끄고 팔을 옮긴 뒤 관절각을 읽어 FK를 돌리면, 그 지점의 로봇 좌표를 얻는다

라이선스·출처는 상위 저장소(`soarm_provided_d`)를 따른다.
